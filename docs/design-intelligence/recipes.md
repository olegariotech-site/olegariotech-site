# OT Design Recipes

Recipes are starting points, not templates.

## Recipe A — Local commerce / WhatsApp-first

Use:
- P01 Commercial Hero;
- P06 Photo-First Catalog;
- P11 Local Discovery;
- P07 WhatsApp Conversion;
- P03 Proof.

Reference mix:
- Shopify for catalog structure;
- Airbnb for image-led browsing/local context;
- Stripe for CTA clarity.

Best for:
- Armazém;
- floriculture;
- food;
- neighborhood commerce.

## Recipe E — Olegario Tech

Use:
- P01 Commercial Hero;
- P02 Cinematic Showcase;
- P03 Proof Before Promise;
- P09 Feature/Benefit Split;
- P08 Method;
- P15 Browser/Device Proof;
- P14 Atmospheric Background;
- P13 Contextual WhatsApp.

Reference mix:
- Framer = atmosphere/showcase;
- Linear = precision/states;
- Stripe = commercial explanation;
- Webflow = demonstrate actual work;
- Apple = subject/spacing;
- Resend = dark editorial restraint.

Do not:
- add a new brand color because a reference uses it;
- replace Earth/particles merely to imitate another system;
- let motion obscure commercial hierarchy.
